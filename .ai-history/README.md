# AI History

本目录保存可随 Git 仓库迁移的当前设计和决策证据，不依赖外部服务。它描述设计，不代替 `AGENTS.md` 的执行规则、`RULE.md` 的重复错误经验或 `docs/` 中的历史计划与发布记录。

## 结构

- `architecture.md`：当前系统边界、依赖和关键约束。
- `modules/`：主要模块的当前职责、行为、接口与证据。
- `decisions/NNNN-*.md`：有证据的重要设计决策；`0001` 是首次基线快照，不追认未知的历史决策。

## 维护与证据

代码修改前阅读相关模块。修改并验证后检查实际 Diff，核对是否改变设计、行为、约束或接口；已获确认的变化更新当前设计，长期取舍另写决策记录。未经确认的冲突先报告，不能修改文档来合理化代码。无设计变化时，在建议的提交说明中说明改动意图。不要自动提交。

每项结论优先引用仓库相对路径、测试名和 Commit。标注 **已确认**（代码、测试或明确记录直接支持）、**推断**（给出依据但未验证）或 **未知**。历史原因只有明确记录时才写为事实。测试结果必须来自实际执行，并注明环境和范围。不要复制个人数据、令牌或密钥。

当前设计文档反映初始化时可见的工作区代码；初始化前已有的修改与当时 `HEAD` 的差异在 `decisions/0001-current-baseline.md` 标明。旧版或尚未验收的能力不能写成原生版已交付能力。
