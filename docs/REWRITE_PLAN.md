# 2.0 原生跨平台重构计划

## 约定

2026-10-28 发布决策更新：用户要求以当前版本合并 GitHub 并发布，覆盖此前“所有功能与三平台验证完成才合并”的时间安排。当前发布为 v2.0.0 Windows x64 便携版；保留旧源码与 v1.0.3 Release，未完成事项继续保留下方清单，不视为已验收。

- 重构分支：`rewrite/slint`。旧版 `main`、v1.0.3 Release、根目录 React/Electron 源码保持可用。
- 新版在 `native/` 独立开发：Rust + Slint，目标 Windows、macOS、Linux，不使用 Electron、WebView2 或 Node.js 运行时。
- 去掉 Excel 导入；保留投递管理、独立流程链、详情编辑、搜索、状态筛选、未完成筛选、统计、日历、托盘、开机启动。
- 只有功能全部完成、数据兼容和跨平台验证通过后才合并 main；本阶段不发布正式版本。
- 5–15 MB 是待验证的体积目标，不是验收承诺。分别记录各平台的程序、压缩包和依赖大小。

## 架构

`native/src/domain.rs` 负责模型、兼容与业务规则；`store.rs` 负责文件和迁移；
`main.rs` 连接模型与 Slint UI；`native/ui/` 负责声明式界面。领域层不依赖 UI。
按 2026-10-28 用户要求，新版默认使用可执行文件旁的 `data/` 目录。
支持 `--data-dir` 指定测试目录，`--import-legacy <文件>` 仅在新目录无数据时导入。
旧 Electron `applications.json` 只能作为导入源，不能作为新版直接写入目标。

## 回退

技术验证阶段直接退出新版、启动旧版即可，旧文件不受影响。正式迁移前额外保存完整备份，
新版如扩展格式须提供格式版本及旧版兼容导出，未完成前不得让用户原地替换唯一数据文件。
