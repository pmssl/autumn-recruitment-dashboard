# 原生界面的旧版样式还原

本轮以 `src/styles.css` 和 `src/main.tsx` 为标准，使用 Slint 重绘，不引入浏览器运行时。

## 已还原

- 86px 白色顶栏、蓝色品牌标记与导航选中线。
- 搜索框、带数量的筛选标签、四张统计卡片。
- 68px 紧凑投递行：公司 / 岗位、彩色状态节点及连线、日期、添加进展同排；长进度链可横向滚动。
- 全部记录表格、阶段统计深色标题区和横条。
- 日历浅蓝日期高亮、状态色节点预览、右侧当天详情。
- 500px 右侧详情抽屉、460px 居中编辑弹窗；弹窗始终覆盖抽屉。
- 自定义按钮和单行输入框，保留键盘和文本输入支持；状态勾号使用矢量绘制，避免字体缺字。

下拉框、文本域与滚动条仍使用 Slint 控件；系统字体渲染与网页可能存在差异，不承诺跨平台像素级一致。

```sh
cargo run --manifest-path native/Cargo.toml -- --capture-ui native/.dev-data/ui-review
```

同时注入鼠标与文字事件，检查编辑输入框获得焦点、文字更新、弹窗保存按钮响应。
截图来自 Slint 窗口渲染，不截取其他桌面内容；该入口不会编入 Release。
