# 秋招看板 v2.0.7

- 日历当天详情和招聘流程的进展行随备注内容调整高度，长备注完整展开，短备注保持紧凑。
- 岗位详情的进展列表为滚动条预留空间，日期与删除按钮不再被遮挡。

Windows x64 用户可直接下载 `autumn-native.exe` 运行，无需安装；也可下载 `Autumn-Dashboard-2.0.7-windows-x64.zip`，内含相同 EXE 和使用说明。首次运行会在 EXE 旁创建 `data/`；升级时请先从托盘退出旧程序，备份原有 `data/`，再替换 EXE。发布附件不包含个人数据。

本次提供 Windows x64 便携程序；macOS/Linux 尚未完成实机验收。Excel 导入、开机启动和重复启动恢复已有窗口仍未提供；程序尚未签名。Slint 仍固定在包含 Windows 重绘修复的上游提交。

验证：14 项原生单元测试、隔离数据冒烟测试和含长备注的 Debug 详情截图检查通过；本地默认 EXE 与本次 Release 构建产物的 SHA-256 一致。附件提供 ZIP 和 EXE 的 SHA-256 校验值。
