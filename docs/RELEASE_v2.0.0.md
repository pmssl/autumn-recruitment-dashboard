# 秋招看板 v2.0.0

本版本将日常使用入口升级为 Rust + Slint 原生桌面程序，延续旧版界面布局，提供 Windows x64 便携版。

## 下载与使用

- 下载 `Autumn-Dashboard-2.0.0-windows-x64.zip`，解压到有写入权限的文件夹，双击 `autumn-native.exe`。
- 无需 Node.js、Electron 或 WebView2；本次不提供安装向导。
- 数据位于程序旁的 `data/applications.json`，保存时备份上一版到 `.bak`。移动程序时一起移动整个 `data` 文件夹。
- 更新已有原生版本：从托盘退出程序，备份 `data`，替换 EXE 后启动。压缩包不包含任何个人数据。
- 旧 Electron 版不会自动迁移。先退出并备份旧版，再以 `--import-legacy "旧数据文件完整路径"` 启动新版；仅允许向尚无数据的新目录导入，源文件保留。可用 `--data-dir` 指定目录。

## 功能

- 公司、岗位和独立进度链管理，投递与进展增删改。
- 搜索、进行中/Offer/结束筛选、有未完成进展筛选。
- 全部记录、阶段统计、日期高亮日历和当天详情。
- Windows 托盘驻留、恢复和退出；关闭窗口后仍可在托盘找到程序。
- 文件锁、写入前备份、原子保存、损坏数据与外部修改保护；启动错误以窗口提示。

## 当前限制

- 本次仅发布 Windows x64；macOS/Linux 尚未完成实机验收和分发。Linux 当前关闭窗口会退出。
- 不包含 Excel 导入、开机启动、再次启动自动恢复已有窗口；目录占用时会提示退出已有实例。
- 未配置代码签名，尚未完成无开发环境新机器、各平台中文输入法及系统关机行为的完整验证。
- v1.0.3 Release 和 Electron 源码保留；如回退，请使用升级前备份，避免覆盖新版期间新增的数据。

## 验证

10 项原生单元测试、Release 构建与隔离数据冒烟测试通过，覆盖投递/进展增删改、持久化、筛选、日历和统计。PE 子系统确认为 Windows GUI，导入表仅包含系统 DLL。发布附件提供 SHA-256 校验值。

EXE 为 9,968,128 字节（约 9.97 MB）；ZIP 约 5.42 MB。
