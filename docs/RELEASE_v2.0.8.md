# 秋招看板 v2.0.8

- 招聘进度列表中的整张投递卡片为纵向滚动条让出空间，卡片边框不再与滚动条相交。
- “全部记录”的表头和投递行在右侧留出一致的空间，避免滚动条遮挡内容；“全部、进行中、有未完成进展、Offer、已结束”筛选均适用。

Windows x64 用户可直接下载 `autumn-native.exe` 运行，无需安装；也可下载 `Autumn-Dashboard-2.0.8-windows-x64.zip`，内含相同 EXE 和使用说明。首次运行会在 EXE 旁创建 `data/`；升级时请先从托盘退出旧程序，备份原有 `data/`，再替换 EXE。发布附件不包含个人数据。

本次提供 Windows x64 便携程序；macOS/Linux 尚未完成实机验收。Excel 导入、开机启动和重复启动恢复已有窗口仍未提供；程序尚未签名。

验证：14 项原生单元测试、隔离数据冒烟测试及含足量虚构投递的 Debug 截图检查通过；本地默认 EXE 与本次 Release 构建产物的 SHA-256 一致。附件提供 ZIP 和 EXE 的 SHA-256 校验值。
